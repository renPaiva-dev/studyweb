# Sinapse — Frontend

Frontend em React + TypeScript + Vite da plataforma de estudos com geração de
flashcards por IA. Veja o [README raiz](../README.md) para visão geral do
projeto, como subir o ambiente completo (backend + frontend + Postgres) e a
documentação funcional em [`Docs/`](../Docs/).

## Desenvolvimento local

```bash
npm install
npm run dev
```

A aplicação sobe em `http://localhost:5173` e espera o backend em
`http://localhost:8080` (ver README raiz para variáveis de ambiente).

## Build

```bash
npm run build
```
